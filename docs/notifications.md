# Notifications

native.cr lets you send and schedule local push notifications — alerts that appear in the device notification tray even when your app is in the background.

> These are **local** notifications generated by the device itself. No internet connection or server is required. For remote push notifications from your own server (APNs / FCM), you would need additional setup not covered here.

---

## Setup — call this first

Before sending any notification, initialise the notification system once — do this in your `setup` method:

```crystal
def setup
  Native::Notifications::Notifications.initialize_default
  # ... rest of your setup
end
```

`initialize_default` creates a single notification channel called `"default"` with high priority. That covers most apps.

---

## Sending a notification immediately

```crystal
Native::Notifications::Notifications.send(
  title: "Hello!",
  body:  "This is a notification from your app."
)
```

Optional parameters:

```crystal
Native::Notifications::Notifications.send(
  title:      "New message",
  body:       "Alice sent you a photo.",
  id:         42,              # integer ID (used to update or cancel later)
  channel_id: "messages"       # Android channel (default: "default")
)
```

---

## Notification with a tap action

```crystal
Native::Notifications::Notifications.send_simple(
  title:  "Download complete",
  body:   "Your file is ready.",
  on_tap: -> { open_file_screen }   # runs when the user taps the notification
)
```

## Scheduling a notification for a future time

```crystal
# Remind in 1 hour
Native::Notifications::Notifications.schedule_reminder(
  title: "Time to take a break!",
  body:  "You've been working for an hour.",
  at:    Time.utc + 1.hour
)

# Schedule at a specific time
meeting_time = Time.local(2026, 6, 25, 14, 30, 0)
Native::Notifications::Notifications.schedule_reminder(
  title: "Meeting reminder",
  body:  "Your team call starts in 10 minutes.",
  at:    meeting_time - 10.minutes,
  id:    101
)
```

---

## Daily repeating reminders

```crystal
# Every day at 8:30 AM
Native::Notifications::Notifications.daily_reminder(
  title:  "Good morning!",
  body:   "Start your day by reviewing your goals.",
  hour:   8,
  minute: 30
)
```

The reminder fires today (or tomorrow if that time has already passed) and repeats every 24 hours.

## Advanced — building a notification manually

Use `Native::Notifications::Notification` when you need features not exposed by the convenience methods:

```crystal
notif = Native::Notifications::Notification.new
notif.id         = 55
notif.title      = "Order shipped"
notif.body       = "Your order #12345 is on its way."
notif.channel_id = "orders"
notif.priority   = Native::Notifications::NotificationPriority::High
notif.auto_cancel = true        # dismiss when tapped
notif.vibration   = true
notif.sound       = nil         # nil = default sound

# Add action buttons
open_action = Native::Notifications::NotificationAction.new(
  "open", "View Order"
) do
  navigate_to_order(12345)
end

notif.actions = [open_action]

# Attach data payload (available when the user taps)
notif.payload = { "order_id" => "12345", "status" => "shipped" }

Native::Notifications::NotificationManager.show(notif)   # => Bool
```

## Scheduling a notification manually

```crystal
notif = Native::Notifications::Notification.new
notif.id             = 200
notif.title          = "Weekly summary"
notif.body           = "Here's what happened this week."
notif.schedule_time  = Time.local + 7.days
notif.repeat_interval = 7.days   # repeat every week

Native::Notifications::NotificationManager.schedule(notif)
```

## Notification priorities

| Priority | Android effect | iOS effect |
|---|---|---|
| `Min` | No heads-up, silent | Delivered quietly |
| `Low` | Appears in shade, no sound | Delivered quietly |
| `Default` | Normal sound + shade | Normal alert |
| `High` | Heads-up banner + sound | Prominent alert |
| `Max` | Most prominent display | Highest priority |

```crystal
notif.priority = Native::Notifications::NotificationPriority::High
```

## Cancelling notifications

```crystal
Native::Notifications::NotificationManager.cancel(42)   # cancel by ID
Native::Notifications::NotificationManager.cancel_all   # cancel everything
```

## Badge numbers (iOS)

Set the red badge number on your app icon:

```crystal
Native::Notifications::NotificationManager.set_badge_number(3)   # show "3"
Native::Notifications::NotificationManager.set_badge_number(0)   # clear badge
```

## Checking and requesting permission

```crystal
if Native::Notifications::NotificationManager.get_permission_status
  puts "Notifications are enabled"
else
  # Show a banner or button asking the user to enable them
  Native::Notifications::NotificationManager.request_permission
end
```

## Custom notification channels (Android)

Android 8+ requires notifications to belong to a channel. `initialize_default` creates one for you, but you can define your own for different categories:

```crystal
orders_channel = Native::Notifications::NotificationChannel.new(
  "orders", "Order Updates"
)
orders_channel.description = "Updates about your orders and deliveries"
orders_channel.importance  = Native::Notifications::NotificationPriority::High
orders_channel.vibration   = true
orders_channel.show_badge  = true

promo_channel = Native::Notifications::NotificationChannel.new(
  "promotions", "Promotions"
)
promo_channel.importance = Native::Notifications::NotificationPriority::Low
promo_channel.show_badge = false

Native::Notifications::NotificationManager.initialize([
  orders_channel,
  promo_channel,
])
```

Then use the channel ID when sending:

```crystal
Native::Notifications::Notifications.send(
  title:      "Your order shipped!",
  body:       "Track it here.",
  channel_id: "orders"
)
```

## Full example — task reminder app

```crystal
class ReminderApp < Native::App
  def setup
    Native::Notifications::Notifications.initialize_default

    task_input = Native::UI::EditText.new
    task_input.hint = "What do you need to do?"
    task_input.width = 300

    remind_btn = Native::UI::Button.new("Remind me in 10 minutes")
    remind_btn.on_click do
      task = task_input.text.strip
      unless task.empty?
        schedule_reminder(task)
        task_input.text = ""
      end
    end

    layout = Native::UI::LinearLayout.new
    layout.orientation = Native::UI::LinearLayout::Orientation::Vertical
    layout.gravity = Native::UI::LinearLayout::Gravity::Center
    layout.set_padding(24, 40, 24, 24)
    layout.addView(task_input)
    layout.addView(remind_btn)
    @root = layout
  end

  def schedule_reminder(task : String)
    Native::Notifications::Notifications.schedule_reminder(
      title: "Reminder",
      body:  task,
      at:    Time.utc + 10.minutes
    )
  end
end
```
